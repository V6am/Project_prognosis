# Walmart Sales Forecasting with ETS

##  Описание проекта

Проект посвящен прогнозированию недельных продаж сети магазинов Walmart с использованием метода экспоненциального сглаживания (ETS — Exponential Triple Smoothing). На основе исторических данных за период 2010–2012 годов построены прогнозы на 4 и 8 недель вперед с доверительными интервалами.

##  Цель

- Построить точные прогнозы Weekly Sales
- Оценить неопределенность прогнозов через доверительные интервалы
- Сравнить точность прогнозов на разных горизонтах (4 и 8 недель)
- Подготовить чистый датасет для дальнейшего анализа

##  Содержимое Excel-файла

| Лист | Описание |
|------|----------|
| `Прогноз на 4 недели` | Исторические Weekly Sales + прогноз ETS на 4 недели с доверительными интервалами |
| `Прогноз на 8 недель` | Исторические Weekly Sales + прогноз ETS на 8 недель |
| `Недели` | Агрегированные недельные продажи |
| `Walmart` | Исходные данные по магазинам (Store, Date, Weekly_Sales, Holiday_Flag, Temperature, Fuel_Price, CPI, Unemployment) |
| `Очистка` | Логи проверки данных (ISNUMBER, ISTEXT) и замены ошибочных значений |

##  Используемые методы

- **ETS (Exponential Triple Smoothing)** — метод прогнозирования временных рядов с учетом тренда и сезонности
- Функции Excel: `FORECAST.ETS`, `FORECAST.ETS.CONFINT`
- Доверительный интервал: 95%
- Сезонность: 1 (автоматическое определение)

##  Ключевые результаты

- Построены прогнозы Weekly Sales с 26.10.2012 по 08.02.2013
- Рассчитаны нижние и верхние границы прогнозов с 95% уверенностью
- Выполнена проверка качества исходных данных (выявление нечисловых значений)

##  Как воспроизвести

1. Открыть файл `Проект_прогнозирования_розничных_продаж.xlsx` в Excel
2. На листах `Прогноз на 4 недели` и `Прогноз на 8 недель` формулы уже применены
3. Для пересчета прогнозов:
   - Изменить диапазон исторических данных (если нужно)
   - Формулы автоматически пересчитаются
4. Лист `Очистка` показывает, какие данные были проверены и скорректированы

##  Используемые данные

- **Источник**: Walmart Sales Data (открытые данные)
- **Период**: 05.02.2010 — 26.10.2012
- **Частота**: недельная
- **Ключевые поля**: Store, Date, Weekly_Sales, Holiday_Flag

##  Ограничения и дальнейшее развитие

**Текущие ограничения:**
- Прогнозы не учитывают праздничные эффекты (Holiday_Flag не интегрирован в ETS в Excel)
- Только один метод прогнозирования (ETS)
- Данные агрегированы по всем магазинам

**Возможные улучшения:**
- Добавить модели SARIMA, Prophet, LightGBM
- Учесть Holiday_Flag как экзогенную переменную
- Построить прогнозы по отдельным магазинам
- Оценить MAE, RMSE, MAPE для разных моделей
